SHAYE V6

New features:
- Announcement popup remains on the dashboard/home page.
- Notification center with unread badge.
- User-to-admin support chat stored in LocalStorage.
- Dark/light theme toggle stored per device.
- Smooth page and panel animations.
- Admin advanced statistics and VIP distribution.
- Full LocalStorage backup export/import.
- No user profile editing, name changing, or password changing was added.

Important:
This is a browser-only LocalStorage project. Chat, users, announcements, and backups are local to the browser/device unless a real backend is added later.
